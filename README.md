# Premier League Points Table Website
A visually appealing and responsive Premier League Points Table website built using HTML5 and CSS3. This project recreates a football standings dashboard inspired by the official Premier League interface, featuring league tables, club statistics, qualification indicators, sponsor sections, and interactive UI components.

# Key Features
1. Complete Premier League points table
2. Team statistics display (Wins, Losses, GD, Points, etc.)
3. Modern dark-themed football UI
4. Sticky navigation bar
5. Interactive hover effects
6. Qualification zone indicators
7. Responsive layout structure
8. Sponsor & partner showcase section
9. Multi-section footer navigation

# Technologies Used
1. HTML5
2. CSS3
3. Google Fonts
4. Flexbox Layout
5. CSS Gradients & Hover Effects
